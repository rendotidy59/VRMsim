        Tentang model

        Simulator ini adalah model semi-empiris untuk edukasi dan analisis what-if. Koefisiennya dipilih agar arah dan orde besaran respons masuk akal untuk VRM raw meal ±400 t/h, bukan hasil validasi terhadap mill tertentu. Jangan gunakan untuk keputusan operasi tanpa kalibrasi dengan data plant.

        Alur perhitungan

        1. Kimia: oksida campuran = Σ proporsi·oksida (basis kering) → basis bebas LOI = oksida/(1−LOI/100). LSF = 100·CaO/(2,8·SiO₂ + 1,18·Al₂O₃ + 0,65·Fe₂O₃); SM = SiO₂/(Al₂O₃+Fe₂O₃); AM = Al₂O₃/Fe₂O₃; Bogue (basis bebas LOI) sebagai indikasi burnability.
        2. Bed & gilas (iterasi titik tetap): tebal bed = kdam·dam·(load index)0,45 − kP·(P−Pnom); daya gilas ∝ P·√(bed/75); energi spesifik = eref·(BWI/BWIref)·(xref/x′)0,5·fbed; kapasitas = daya gilas / energi spesifik; load ratio = feed kering / kapasitas.
        3. Separator & PSD: x′ = xref·(rpmref/rpm)1,1·(gas/gasref)0,6·L0,3; R(x) = 100·exp(−(x/x′)n) → R90, R200. Circulating load = CLref·(rpm/rpmref)1,3·L1,2·(gas/gasref)−0,8.
        4. DP mill = DPgas·(gas/gasref)1,8 + DPload·load index + kdam·(dam−150).
        5. Getaran = dasar + suku bed tipis + suku tekanan/bed + suku bed tebal + suku overload + suku material kering.
        6. Neraca panas: mgcp(Tin−Tout) + panas gilas = Qevap + pemanasan material + false air + rugi dinding, dengan Qevap = mair·(2500 kJ/kg + cp,uap·ΔT) → Tout. Moisture produk = f(Tout, moisture umpan, waktu tinggal).
        7. Energi: kWh/t = (daya mill + fan + separator)/throughput; daya fan = Qaktual·(DP mill + DP sistem)/η. MJ/t = panas yang diserahkan gas / throughput. CO₂ = kWh/t·EFgrid + MJ/t·fraksi bahan bakar·EFbahan bakar.
        8. Dinamika: delay belt, dead time + lag orde-1 untuk bed, suhu, DP, PSD, kimia; PID untuk suhu outlet dan DP; interlock trip.

        Keterbatasan utama

        • Tidak memodelkan keausan roller/meja, distribusi aliran gas non-uniform, pembentukan "rat hole", atau perilaku hidrolik akumulator.
        • Separator diwakili satu ukuran karakteristik Rosin-Rammler; kurva Tromp tidak dimodelkan eksplisit.
        • Throughput tunak = feed (neraca massa); kapasitas gilas memengaruhi sirkulasi, DP, kehalusan dan getaran.
        • Emisi CO₂ dan dampak ke kiln bersifat indikatif.
